# 奶蛙狂笑

一个纯静态的奶蛙互动网页。点击页面中的奶蛙即可播放大笑视频，页面只包含奶蛙和必要的控制按钮，支持明暗主题、音量调节、大笑计数和 PWA 安装。

## 功能

- 点击奶蛙播放大笑视频和声音；首次点击才加载视频，兼容移动端浏览器的用户手势限制
- 播放结束后显示“笑完啦，再点一次”，约 1.6 秒后自动回到初始状态；开启循环后不复位
- 支持“循环大笑”“停止”两个底部控制
- 右上角紧凑按钮：显示模式、音量、大笑次数
  - 显示模式：电脑（跟随系统）/ 太阳（白天）/ 月亮（黑夜），点击循环切换并本地保存
  - 音量：图标按钮，点击后弹出滑块和声音开关，默认音量 30%
  - 次数：默认只显示数字，点击切换“已笑 x 次”，按钮宽度随数字位数增长
- 右下角信息按钮：本站运行时间、访问人次、访问人数、版权信息、素材来源
- PWA：可安装到设备主屏幕，支持独立窗口打开与基础离线缓存

## 本地预览

项目无任何依赖和构建步骤。在项目根目录启动一个静态服务器即可：

```bash
python -m http.server 8765
```

然后访问 <http://localhost:8765>。

> 直接双击打开 `index.html` 也可以看到页面，但 Service Worker 和 PWA 安装需要 HTTP/HTTPS 环境。

## 部署到 Cloudflare Pages

1. 在 Cloudflare Pages 创建新项目，连接本仓库或直接上传项目目录。
2. 构建配置：
   - 构建命令：留空
   - 构建输出目录：`/`（项目根目录）
3. 部署完成后，Cloudflare Pages 会自动提供 HTTPS 域名。
4. 在浏览器中打开站点，通过浏览器菜单中的“安装应用 / 添加到主屏幕”即可安装为 PWA。

如果使用自定义域名，PWA 的 Service Worker 作用域为站点根目录，无需额外配置。

## PWA 说明

- `manifest.webmanifest` 声明了应用名称、独立显示模式、主题色和 192/512 图标。
- `sw.js` 预缓存页面、样式、脚本和素材；视频分段请求仍走网络，避免 Range 请求与缓存冲突。
- 图标来自 milkyfrog.com 官网的 `apple-touch-icon.png`，仅做尺寸缩放，没有重新设计图案。
- 修改页面后如发现缓存未更新，可将 `sw.js` 中的 `CACHE_NAME` 版本号递增。

## 其他说明

- 访问人次与人数使用浏览器 `localStorage` 记录，仅代表本机数据；页面保留了 `page_pv` 和 `page_uv` 元素 ID，方便后续接入真实统计服务。
- 运行时间从固定起点实时计算，起点写在 `app.js` 的 `renderUptime` 附近，可按需修改。
- 主题选择保存在 `localStorage`，选择“跟随系统”时会实时响应系统深浅色变化。
